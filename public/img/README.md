# Изображения участников группы

Поместите в эту папку фотографии участников:

- `artur.jpg` - Артур (вокал)
- `damir.jpg` - Дамир (бас-гитара)
- `gosha.jpg` - Гоша (гитара)
- `kostya.jpg` - Костя (гитара)
- `gleb.jpg` - Глеб (барабаны)
- `vlad.jpg` - Влад (вокал)

## Рекомендации:
- Формат: JPG или PNG
- Разрешение: минимум 400x400px
- Стиль: тёмные, мрачные, концертные фото
- Изображения будут затемнены для сохранения стиля сайта

Опционально:
- `bloody-scissors-bg.jpg` - фон для центральной ячейки
